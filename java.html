1. Introduction to Java

Java is a high-level, object-oriented, class-based programming language designed to be portable, secure and robust.

Platform Independent
Java bytecode runs on the JVM.
Object Oriented
Programs are organized around objects and classes.
Robust
Strong type checking and exception handling.
Secure
Runtime checks and controlled memory access.

2. JDK, JRE and JVM

  • JVM: Executes Java bytecode.
  • JRE: JVM + libraries required to run Java applications.
  • JDK: JRE + development tools such as javac.
Flow: Java source (.java) → javac → Bytecode (.class) → JVM → Machine code

13. Constructors

class Student {
    String name;
    int age;

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

A constructor has the same name as its class and has no return type.

14. Inheritance

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

Java supports single, multilevel and hierarchical inheritance through classes. Multiple inheritance of classes is not supported.

15. Polymorphism

Method Overloading

int add(int a, int b) { return a+b; }
double add(double a, double b) { return a+b; }

Method Overriding

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }
}

16. Abstraction

abstract class Vehicle {
    abstract void start();

    void stop() {
        System.out.println("Stopped");
    }
}

class Car extends Vehicle {
    void start() {
        System.out.println("Car starts");
    }
}

17. Encapsulation

class Account {
    private double balance;

    public void setBalance(double balance) {
        if (balance >= 0) this.balance = balance;
    }

    public double getBalance() {
        return balance;
    }
}

24. Multithreading

class MyTask extends Thread {
    public void run() {
        System.out.println("Thread running");
    }
}

public class Main {
    public static void main(String[] args) {
        MyTask t = new MyTask();
        t.start();
    }
}

Learn thread lifecycle, Runnable, synchronization, locks, executors and concurrent collections.

26. Stream API

List<Integer> nums = List.of(1,2,3,4,5,6);

nums.stream()
    .filter(n -> n % 2 == 0)
    .map(n -> n * n)
    .forEach(System.out::println);

Important operations: filter(), map(), sorted(), distinct(), reduce(), collect(), forEach().

27. JDBC

JDBC connects Java applications with relational databases.

Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/test",
    "root",
    "password"
);

PreparedStatement ps =
    con.prepareStatement("SELECT * FROM students");

ResultSet rs = ps.executeQuery();

while (rs.next()) {
    System.out.println(rs.getString("name"));
}

con.close();
